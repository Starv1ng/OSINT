Bienvenido

Sistema profesional de inteligencia de fuentes abiertas con detección automática de tipo de input y selección inteligente de módulos. Proporciona resultados filtrados, puntuados y ordenados por relevancia.

Características Principales

Detección Inteligente

Detección automática del tipo de input (persona, correo, dominio, nombre de usuario, etc.) y selección de módulos apropiados para búsqueda óptima.

Filtrado Automático

Eliminación automática de ruido (atributos HTML, spam, parámetros inútiles) para obtener resultados limpios y relevantes.

Evaluación Automática

Los hallazgos se puntúan automáticamente (0.0-1.0) según relevancia y se ordenan por importancia.

Módulos Adaptables

Selección dinámica de módulos según el tipo de input. Fallback automático si alguno no está disponible.

Búsqueda Iterativa

Extracción automática de indicadores y búsquedas adicionales en iteraciones posteriores.

Estadísticas en Tiempo Real

Monitoreo en tiempo real del progreso con estadísticas detalladas de resultados.
