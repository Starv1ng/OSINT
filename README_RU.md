# OSINT Intelligence Platform (Version Beta 0.01)

## Описание

Распределенная OSINT (Open Source Intelligence) платформа с микросервисной архитектурой для автоматизированного сбора и анализа информации из открытых источников.

## Архитектура

Система состоит из следующих компонентов:

- **API Service** (FastAPI) - REST-шлюз и веб-интерфейс
- **Worker Service** (Celery) - Асинхронное выполнение задач
- **PostgreSQL** - Хранение заданий и статусов
- **Redis** - Брокер сообщений для очереди задач
- **Elasticsearch** - Индексация и поиск результатов
- **MinIO** - Хранение файлов и артефактов
- **Neo4j** - Граф связей и сущностей

## Функциональность

### Анализ входных данных (работаю над этим)
- Автоматическое определение типа входных данных (email, username, домен, имя, телефон, URL, IP, хэш)
- Оценка уверенности классификации (0.0-1.0)
- Извлечение вторичных индикаторов из входных данных

## Установка

### Требования
- Docker 20.10+
- Docker Compose 2.0+
- Минимум 8GB RAM
- 20GB свободного места на диске

### Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/Starv1ng/OSINT.git
cd OSINT

# Запустить все сервисы
docker-compose up -d

# Просмотр логов
docker-compose logs -f api worker

# Доступ к веб-интерфейсу
# http://localhost:8000
```

## Текущие ограничения

- Не настроены реальные API-ключи (модули возвращают mock-данные)
- Аутентификация отключена в режиме разработки
- Ограниченная реализация rate limiting
- Отсутствует слой кэширования для повторных запросов
- Базовая обработка ошибок в некоторых модулях
